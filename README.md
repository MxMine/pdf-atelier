# PDF Atelier Studio

Lire, modifier, signer, créer et convertir des PDF, sur Windows et Android. Sans compte, sans abonnement, sans publicité.

1. Version Windows sur le Microsoft Store : [PDF Atelier Studio](https://apps.microsoft.com/detail/9P3MWBSFWJT3)
2. Page du projet : https://mxmine.github.io/pdf-atelier
3. Politique de confidentialité : https://mxmine.github.io/pdf-atelier/confidentialite.html
4. Code source de chaque version : onglet [Releases](https://github.com/MxMine/pdf-atelier/releases) (fichier `PDF-Atelier-<version>-sources.zip`)
5. Contact et signalements : davidpercot@outlook.fr
